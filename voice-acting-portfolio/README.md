# Voice Acting Portfolio

## Overview
This project is a voice acting portfolio designed to showcase audio files organized by character and project. The portfolio features expandable categories for different sound types and links to audio files hosted on cloud storage, such as Google Drive.

## Project Structure
```
voice-acting-portfolio
├── src
│   ├── assets
│   │   ├── audio          # Contains links to audio files organized by character and project
│   │   └── images         # Holds images related to the portfolio
│   ├── css
│   │   ├── main.css       # Main styles for layout, typography, and responsive design
│   │   └── styles.css     # Additional styles for specific components or pages
│   ├── js
│   │   ├── audio-player.js # Functionality for the audio player
│   │   └── main.js        # Manages interactive elements of the portfolio
│   └── pages
│       ├── characters.html # Showcases voice acting roles sorted by character
│       ├── index.html      # Main landing page of the portfolio
│       └── projects.html    # Showcases voice acting roles sorted by project
├── LICENSE                 # Licensing information for the project
└── README.md               # Documentation for the project
```

## Setup Instructions
1. Clone the repository to your local machine.
2. Navigate to the project directory.
3. Open `index.html` in your web browser to view the portfolio.

## Features
- Organized audio files by character and project.
- Expandable categories for different sound types.
- Responsive design for optimal viewing on various devices.
- Audio player functionality for seamless playback of audio files.
